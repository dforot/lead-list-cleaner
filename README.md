# Lead List Cleaner

A small Python/Streamlit business-automation demo for cleaning and quality-checking lead spreadsheets.

The app automatically loads `demo_leads.csv` on first visit so the public page is not an empty form.

## What it demonstrates
- CSV/XLSX ingestion
- Text and URL normalization
- Duplicate detection
- Missing-field checks
- Cleaned Excel export
- Browser-based business UI

This is a self-created portfolio demonstration and is not presented as client work.
