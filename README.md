# Lead List Cleaner — Upwork Portfolio Demo

Self-created demonstration project. It is not presented as client work.

## What it demonstrates
- Python business automation
- CSV/XLSX ingestion
- Data cleaning and normalization
- Duplicate detection
- Missing-field QA
- Excel export
- Simple business-facing interface

## Run locally
1. Install Python 3.11+.
2. Open a terminal in this folder.
3. Run: `pip install -r requirements.txt`
4. Run: `streamlit run app.py`
5. Upload `demo_leads.csv`.

## Portfolio positioning
The tool demonstrates how a repetitive spreadsheet-cleaning workflow can be turned into a reusable business tool.
